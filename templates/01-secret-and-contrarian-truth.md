## 2 · Is it a secret?

| Test | Yes / No | Evidence |
|---|---|---|
| Is it true? What would prove you wrong? | | |
| Is it important? If true, how big is the X it unlocks? | | |
| Do most smart people in the field disagree, or have they not thought about it? | | |
| Is it findable but hard (a secret), rather than obvious (a convention) or out of reach (a mystery)? [CS183-11] | | |
| Is it a secret about nature, about people, or both? [CS183-11] | | |
| Is it a concrete piece inside a big trend, not the trend itself? [AMA14] | | |

If most people would nod when you say it, it isn't a secret.
