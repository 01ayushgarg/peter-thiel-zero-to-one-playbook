# Template 02 · Market reality check

Find out whether you're in a real small market you can own, or a fictional one inside a big competitive
market. Source: `references/02-competition-is-for-losers.md`, `references/03-building-a-monopoly.md`
[YCL5, WSJ14].

His one question: "what is the actual market? So not what's the narrative of the market" [YCL5].

## 1 · X and Y

| | Your answer |
|---|---|
| X: value you create for the world, per year, in dollars | |
| Y: share of X you can keep (price × customers ÷ X) | |
| What stops Y from being competed to zero? | |

Remember his airlines: huge X, and in 2012 they "made only 37 cents per passenger trip" [WSJ14].

## 2 · The intersection test (the lie startups tell)

Write your market as you pitch it, then drop one qualifier at a time.

| Step | Market description | Who else serves it | Size ($/yr) | Your share |
|---|---|---|---|---|
| Pitch version (all qualifiers) | e.g. AI scheduling for Austin dog groomers | | | |
| Drop one qualifier | | | | |
| Drop another | | | | |
| What customers actually substitute for you | | | | |

**Red flag:** your category only exists because of the adjectives. "The something of somewhere is really mostly
just the nothing of nowhere" [YCL5].

## 3 · The union test (the lie incumbents tell)

If you were already dominant and wanted to look small, what giant market would you say you're in?
______________ Your share of that: ______ %

If the union story feels more honest than your pitch, you're probably in a competitive market.

## 4 · Small enough to own?

| Question | Answer |
|---|---|
| Who exactly is the first market? Name the group and count it (his PayPal power sellers: "about twenty thousand people" [YCL5]) | |
| Can you reach a large share of them fast? (Facebook at Harvard: "zero to sixty percent market share in ten days" [YCL5]) | |
| Who else is chasing this exact group today? | |
| Is the market you start in measured in billions? If yes, be suspicious: cleantech decks "started with massive markets" [YCL5] | |

## 5 · Verdict

- [ ] **Real small market:** countable, reachable, nobody else serving it well.
- [ ] **Fictional intersection:** the real market is broad and crowded. Rethink the wedge.
- [ ] **Too big to start:** you'd be "a minnow in a vast ocean" [YCL5]. Find the small piece.
